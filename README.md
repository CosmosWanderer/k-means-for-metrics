# k-means-for-metrics
A tool for clustering function calls by metrics.

## Setting up tool
### Linux
```bash
chmod +x setup.sh
./setup.sh
chmod +x run.sh
```
### Windows
```
setup.bat
```

## Running tool
### Linux
```bash
./run.sh metrics_example.csv
```
### Windows
```cmd
run.bat metrics_example.csv
```
